## THE PRODUCT

Questbook helps you see yourself clearly enough to choose where you want to go.

**What it is:**
- Self-discovery system
- Evidence-based skill detection
- Living workbook that evolves with you
- Progressive understanding (not a funnel)

**What it is NOT:**
- Business-building course
- Career counselor
- Personality typing system

## KEY PRINCIPLES

**Reveal, not prescribe**
- Show patterns, don't declare conclusions
- Surface possibilities, don't prescribe paths

**One Ring & Seven Rings**
- One Ring = core strength (centre of gravity)
- Seven Rings = wider ecosystem (all of you)

**Living Workbook**
- Users return and retake modules
- Version 01, 02, 03 track evolution
